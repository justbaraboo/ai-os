# AI-OS Bootstrap

This repository contains structured operational knowledge.

## Entry Points

1. manifest.yaml
2. skills/
3. memory/facts/
4. memory/decisions/
5. snapshots/latest/

## Operating Instructions

- Use progressive disclosure.
- Load only relevant skills.
- Do not treat chat as long-term memory.
- Skills are source of operational logic.
- ADR files document decisions.

When initializing:
1. Read manifest.yaml
2. Read latest snapshot (if exists)
3. Index available skills
4. Ask user what domain to operate in
